갈무리 개인정보처리방침

게시자: 자족 · 시행일: 2026년 11월 8일

한눈에 보기

  • 캡처, 메모, 노트는 사용자 컴퓨터의 브라우저 안에만 저장돼요. 개발자는 별도 서버를 운영하지 않고, 사용자 데이터를 받거나 볼 수 없어요.
  • 사용자가 직접 질문하거나 요약을 요청할 때만 해당 캡처와 질문이 사용자 본인의 API 키로 Google Gemini API에 전송돼요.
  • 광고, 사용자 추적, 분석 도구를 쓰지 않고, 데이터를 팔거나 다른 곳에 넘기지 않아요.

1. 이 방침이 적용되는 대상

이 방침은 크롬 확장 프로그램 "갈무리"(이하 "확장 프로그램")에 적용돼요. 확장 프로그램은 웹페이지 화면 일부를 캡처하고, 캡처 위에 메모와 표시를 남기고, Gemini에게 질문한 내용과 함께 노트로 정리하는 도구예요.

2. 처리하는 정보와 저장 위치

정보언제 생기나요어디에 저장되나요
캡처 이미지, 그 위의 펜·도형·포스트잇 메모사용자가 캡처하고 표시할 때사용자 브라우저(확장 프로그램 저장소)
질문, Gemini의 답변, 내 메모, 노트 요약사용자가 질문·메모·요약할 때사용자 브라우저
캡처한 페이지의 주소, 제목, 스크롤 위치, 캡처 영역 근처의 문장 한 줄캡처하는 순간사용자 브라우저 ("캡처한 위치로 가기"에 사용)
Gemini API 키사용자가 설정에서 연결할 때사용자 브라우저(chrome.storage.local)
설정(단축키 안내 표시 여부, 창 크기, 백업 폴더 등)사용할 때사용자 브라우저
백업 파일자동 백업 또는 [지금 백업]을 할 때사용자가 고른 폴더 또는 다운로드 폴더

위 정보는 개발자에게 전송되지 않으며, 개발자는 이를 수집하거나 열람할 수 없어요.

3. 외부로 전송되는 정보 (Google Gemini API)

사용자가 [묻기], 빠른 질문(요약해줘·설명해줘·번역해줘), [이어서 묻기], 노트 요약을 실행할 때에만 아래 정보가 사용자 본인의 Gemini API 키로 Google에 전송돼요.

  • 캡처 이미지(사용자가 그린 펜·도형·형광펜 표시 포함)
  • 사용자가 입력한 질문
  • 해당 캡처의 포스트잇 메모와 내 메모 내용(답변의 맥락으로 사용)
  • 같은 캡처에서 이전에 주고받은 질문과 답(이어서 묻기)
  • 노트 요약을 요청한 경우, 그 노트에 있는 질문·답·메모 텍스트

전송된 정보는 Google의 정책에 따라 처리돼요. Gemini API 무료 등급을 쓰는 경우, Google이 보낸 내용을 서비스 개선에 사용할 수 있어요. 자세한 내용은 Gemini API 추가 서비스 약관과 Google 개인정보처리방침을 확인해 주세요. 개인정보나 회사 기밀이 보이는 화면은 질문하지 않는 것을 권장해요.

Gemini 키를 연결하지 않으면 어떤 정보도 외부로 전송되지 않아요.

4. 권한을 쓰는 이유

  • 현재 탭 접근, 스크립트 실행: 단축키·툴바 아이콘·오른쪽 클릭 메뉴로 캡처를 시작했을 때, 그 탭 화면을 찍고 캡처 범위를 고르는 화면을 띄우기 위해
  • 저장소: 노트와 설정을 사용자 브라우저에 저장하기 위해
  • 클립보드: [복사]로 캡처를 클립보드에 넣고, Gemini 키 연결 중에만 사용자가 복사한 키를 읽어오기 위해(연결 후 클립보드에서 키를 지워요)
  • 다운로드: 내보내기와 백업 파일을 저장하기 위해
  • 오른쪽 클릭 메뉴, 단축키, 알림 배지: 캡처와 노트를 쉽게 열기 위해
  • Google AI Studio, Gemini API 주소 접근: 키 발급 안내창을 띄우고, 사용자가 질문할 때 Gemini에 요청하기 위해

5. 하지 않는 것

  • 광고, 사용자 추적, 방문 기록 수집, 분석 도구 사용을 하지 않아요.
  • 사용자 데이터를 판매하거나, 광고 목적으로 쓰거나, 제3자에게 넘기지 않아요.
  • 사용자가 캡처하지 않은 페이지 내용을 읽지 않아요.
  • 외부에서 코드를 내려받아 실행하지 않아요.

이 확장 프로그램의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책(제한적 사용 요건 포함)을 준수해요.

6. 보관 기간과 삭제

  • 노트와 캡처는 사용자가 지울 때까지 사용자 브라우저에 남아 있어요. 노트 화면에서 캡처나 노트를 삭제할 수 있어요.
  • Gemini 키는 설정의 [연결 해제]로 언제든 지울 수 있어요.
  • 확장 프로그램을 삭제하면 브라우저에 저장된 노트, 설정, 키가 함께 지워져요.
  • 백업 파일은 사용자 컴퓨터의 파일이라, 필요 없으면 사용자가 직접 삭제하면 돼요.
  • Google로 전송된 정보의 보관과 삭제는 Google의 정책을 따라요.

7. 아동

이 확장 프로그램은 만 14세 미만 아동을 대상으로 하지 않아요.

8. 방침 변경

기능이 바뀌어 처리하는 정보가 달라지면 이 페이지를 업데이트하고, 위쪽의 시행일을 바꿔 알려드려요. 중요한 변경은 확장 프로그램 업데이트 안내에도 적을게요.
